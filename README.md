Bounce Man Expeditions

Bounce Man Expeditions is a game about a character (Bounce Man) having to grab supplies for his ship in “The Ruins”. Level 2 introduces our bouncing mechanism where you use the same controls to double jump but it’ll shoot you higher. The game uses the regular arrow/awsd keys to move Bounce Man and space to jump. 
Produced By: Lumen Harris, Alex Park, Sandra Lemus Gomez
